# BH26-SemClinVar
The goal of this project is to update the current ClinVar RDF model in RDFPortal. 

## RDFPortal
### ClinVar RDF converter
The ClinVar RDF converter is available at the following repository: https://github.com/med2rdf/clinvar

### ClinVar RDF model
The RDF-config model for ClinVar RDF is in `model.yaml` here: https://github.com/dbcls/rdf-config/tree/master/config/clinvar

### Genome Variation Ontology
DBCLS, Nagasaki Lab at Kyushu Univ., and other colleagues regularly organize VISC (Variant Information Standardization Collegium), a research meeting focused on genomic variation. As part of this initiative, we have also developed resources such as the [Genome Variation Ontology](http://genome-variation.org/resource/gvo) to describe genomic structural variants.
